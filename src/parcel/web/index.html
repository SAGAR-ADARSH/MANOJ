How to read these numbers

  • Recall at capacity is the share of truly late parcels that receive one of the limited intervention slots.
  • Expected net benefit uses an assumed 40% intervention success rate and ₹450 avoided late cost. It is not measured causal profit.
  • The bootstrap resamples whole days. It quantifies sampling variability in this synthetic set, not real-world uncertainty.
  • A new carrier is a known weak spot: the model has no carrier-specific history for it.

Leakage boundary

The label is delivery_at > original promise_at. Delivery time, final status, exception code, rating, actual cost, and revised promises are never model features. Training rows whose outcomes would not be mature by the next time partition are purged.

What happens when it breaks

  • Missing columns, naive timestamps, duplicate IDs, unknown carriers, impossible values → clear rejection.
  • Drift warning → review the batch and recent labeled outcomes before acting.
  • Missing model artifact → the API returns 503 with the exact training command.
  • Capacity is hard-capped by day, carrier, and warehouse. Greedy allocation is auditable but not proven globally optimal.
